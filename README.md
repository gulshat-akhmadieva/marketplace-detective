# Маркетплейс-детектив

**Маркетплейс-детектив** — мини-сервис для первичного аудита карточки товара на маркетплейсе.

Сервис помогает быстро оценить, насколько карточка товара здорова с точки зрения unit-экономики, рекламы, воронки продаж, контента и остатков.

## Что делает сервис

- считает unit-экономику карточки;
- показывает прибыль на заказ до и после рекламы;
- рассчитывает маржинальность и чистую маржинальность;
- считает ДРР, CTR, конверсию и корзину → заказ;
- оценивает остатки в днях;
- рассчитывает точку безубыточности;
- показывает максимальный и комфортный рекламный бюджет;
- проверяет сценарий “что если?”;
- формирует приоритет задач: срочно исправить, можно улучшить, наблюдать;
- генерирует план улучшения карточки на 7 дней;
- формирует отчёт;
- позволяет скопировать отчёт или скачать его в Markdown;
- сохраняет историю последних аудитов в браузере.

## Бизнес-логика

Сервис не подключается к API маркетплейсов. Все данные вводятся вручную, поэтому инструмент можно использовать для быстрой первичной диагностики товара, презентации идеи, консультации или разбора карточки.

Основные расчёты:

- прибыль на 1 заказ до рекламы;
- прибыль на 1 заказ после рекламы;
- точка безубыточности по цене;
- рекламный расход на заказ;
- максимальный рекламный бюджет до нуля;
- комфортный рекламный бюджет;
- запас товара в днях;
- сценарное сравнение текущих и изменённых параметров.
