Маркетплейс-детектив

Мини-сервис для первичного аудита карточки товара на маркетплейсе. Считает unit-экономику, рекламную нагрузку, точку безубыточности, проверяет сценарий “что если?” и формирует план улучшений на 7 дней.

Данные карточки

Без API. Данные вводятся вручную для быстрой бизнес-диагностики товара, рекламы, остатков и экономики карточки.
